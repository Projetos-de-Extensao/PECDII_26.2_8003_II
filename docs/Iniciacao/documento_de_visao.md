## Introdução

O propósito deste documento é apresentar uma visão geral do projeto de desenvolvimento de um sistema web para gerenciamento do Teste Progresso. Neste documento serão descritos de maneira resumida o problema a ser abordado, os usuários envolvidos, os objetivos da equipe, a solução proposta e os principais recursos que serão disponibilizados pelo sistema.

O sistema será desenvolvido com foco na organização das informações relacionadas aos alunos, cursos, unidades, salas e fiscais envolvidos na aplicação do Teste Progresso.

## Descrição do Problema

A aplicação do Teste Progresso envolve uma grande quantidade de alunos, diferentes cursos, unidades e salas, além da necessidade de organização dos fiscais responsáveis pela aplicação das avaliações.

A quantidade de informações e participantes envolvidos pode tornar o processo de organização mais complexo, dificultando o controle dos alunos, sua distribuição nas salas e a organização dos fiscais.

### Problema

A dificuldade em gerenciar e organizar uma grande quantidade de alunos, cursos, salas, unidades e fiscais envolvidos na aplicação do Teste Progresso.

### Impactados

Os principais impactados são os usuários envolvidos na organização e realização do Teste Progresso, principalmente a coordenação, os professores e os alunos.

A equipe responsável pela organização também pode ser impactada pela dificuldade de centralizar e consultar as informações necessárias para a realização das avaliações.

### Consequência

A falta de uma ferramenta centralizada para gerenciamento das informações pode dificultar a organização dos alunos nas salas, o controle dos fiscais e o gerenciamento das unidades e cursos envolvidos na aplicação do Teste Progresso.

### Solução

Desenvolver uma aplicação web para centralizar e organizar as informações relacionadas ao Teste Progresso.

A aplicação deverá permitir o gerenciamento dos usuários, cursos, alunos, unidades, salas e fiscais, possibilitando relacionar essas informações e facilitar a organização das avaliações.

## Objetivos

O objetivo da equipe de desenvolvimento é fornecer uma aplicação web capaz de auxiliar na gestão e organização do Teste Progresso.

A aplicação deverá centralizar as principais informações utilizadas no processo, permitindo:

- Gerenciar os usuários envolvidos no sistema;
- Gerenciar os cursos participantes do Teste Progresso;
- Gerenciar os alunos e relacioná-los aos seus respectivos cursos;
- Gerenciar as unidades onde serão realizadas as avaliações;
- Gerenciar as salas disponíveis em cada unidade;
- Organizar os alunos nas salas;
- Gerenciar os fiscais responsáveis pelas salas;
- Relacionar os fiscais às respectivas salas;
- Facilitar a consulta das informações necessárias para a organização das avaliações.

## Descrição do Usuário

Os usuários do sistema serão divididos de acordo com sua participação no processo do Teste Progresso.

A **coordenação** será responsável principalmente pelo gerenciamento e organização das informações relacionadas às avaliações, incluindo alunos, cursos, unidades, salas e fiscais.

Os **professores** poderão utilizar o sistema para consultar informações relacionadas à organização e realização das avaliações.

Os **alunos** estarão cadastrados no sistema e terão suas informações relacionadas ao respectivo curso e à sala em que realizarão a avaliação.

## Recursos do produto

### Usuários

O sistema deverá permitir o gerenciamento dos usuários envolvidos no Teste Progresso, considerando diferentes tipos de usuários, como coordenação, professores e alunos.

As informações dos usuários deverão ser armazenadas e relacionadas às demais informações necessárias para o funcionamento da aplicação.

### Cursos

O sistema deverá permitir o cadastro e gerenciamento dos cursos participantes do Teste Progresso.

Os alunos deverão estar relacionados aos seus respectivos cursos para facilitar a organização das avaliações.

### Alunos

O sistema deverá permitir o gerenciamento das informações dos alunos participantes do Teste Progresso.

Os alunos deverão ser relacionados aos seus respectivos cursos e às salas destinadas à realização das avaliações.

### Unidades

O sistema deverá permitir o cadastro e gerenciamento das unidades onde serão realizadas as avaliações.

Cada unidade deverá possuir suas respectivas salas disponíveis para a aplicação do Teste Progresso.

### Salas

O sistema deverá permitir o cadastro e gerenciamento das salas utilizadas para a realização das avaliações.

As salas deverão estar relacionadas às respectivas unidades e poderão ser utilizadas para organizar os alunos e os fiscais.

### Organização dos alunos

O sistema deverá permitir a distribuição e organização dos alunos nas salas disponíveis para a realização das avaliações.

A organização deverá considerar a quantidade de alunos por sala, possibilitando um melhor controle da distribuição dos participantes.

### Fiscais

O sistema deverá permitir o gerenciamento dos fiscais responsáveis pela aplicação das avaliações.

Os fiscais deverão ser relacionados às salas onde atuarão, permitindo que a coordenação tenha uma visão organizada da distribuição dos responsáveis pela fiscalização.

## Restrições

A aplicação será desenvolvida como um projeto acadêmico durante o semestre de 2026.2, estando limitada ao escopo definido pela equipe para a primeira versão do sistema.

O sistema terá como foco o gerenciamento e a organização das informações relacionadas ao Teste Progresso, não sendo responsável por processos que não estejam relacionados ao escopo definido para esta versão.

A aplicação dependerá de uma estrutura de backend e banco de dados para armazenamento e gerenciamento das informações.

Novas funcionalidades poderão ser analisadas e incorporadas em versões futuras do sistema, caso sejam identificadas novas necessidades durante o desenvolvimento do projeto.
