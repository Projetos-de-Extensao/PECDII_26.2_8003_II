# Projeto Back-End: Sistema de Gestão do Teste Progresso

## Sobre

Sistema web para organizar a aplicação do Teste Progresso na instituição.
Ele cadastra unidades, salas, cursos e turmas, distribui os alunos pelas salas
respeitando a capacidade de cada uma, aloca professores fiscais e envia
notificações aos participantes.

A documentação de requisitos, casos de uso e diagrama de classes está no site do projeto.

## Funcionalidades

- Cadastro de unidades, salas, cursos e turmas
- Perfis de usuário (aluno, professor e coordenação), com cadastro de alunos e professores
- Ensalamento de alunos, com controle de capacidade da sala
- Alocação de professores fiscais por sala, data e turno
- Notificações para os usuários

### Em desenvolvimento

- Teste Progresso, inscrições e resultados

## Tecnologias

- Python e Django
- MkDocs (documentação)
- GitHub e Visual Studio Code
